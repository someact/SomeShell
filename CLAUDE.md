# SomeShell

Personal Hyprland desktop for three machines. Detect every hardware feature at runtime, never assume one.
- Desktop: CachyOS x86_64, Hyprland 0.56 Lua config, RTX 3060, DP-1 and HDMI-A-1 1920x1080@100, Ethernet only (no Wi-Fi), US/TH keyboard, UGTablet pen, monitors dimmed over DDC.
- Laptop: Legion 5, RTX 3060 Mobile, eDP-1 2560x1440@165, touchpad, battery.
- Tablet (added 2026-11-02): Xiaomi Pad 6 (`pipa`), aarch64 Snapdragon 870 (SM8250), Adreno 650 on Mesa freedreno, panel DSI-1 1800x2880@120 portrait (turned to landscape with transform 3, scale 2), 8 GB RAM / 256 GB storage, Arch Linux ARM (`linux-pipa` kernel) dual-booted with Android through the A/B slots (one slot each, storage split 128/128). Backlight `ktz8866-backlight`, battery `qcom-battery`. Used with keyboard and mouse, so touch is not a priority. It is where battery, Wi-Fi, backlight brightness and SDDM get tested.
Called SomeHypr until Phase 12; only the installer may use the old name.
Current work: a full rebuild from scratch (2026-11-02). Base (steps 1–4) is done and live on the desktop. The design and decisions are in `SomeShell.md`; tasks are tracked in `docs/plan.md` (one step at a time, tick tasks in the commit that finishes them).
SomeShell Reimagined (`../SomeShell-Reimagined`) is a fork; its `scripts/switch.sh someshell|reimagined` relinks a machine between the two.

## Working on several machines
- One repo for all three. Run `git pull` before starting and push after each verified task, so the machines never diverge. Work on one machine at a time.
- Machine-specific things never go into the repo: they live in `~/.config/someshell/` (`hypr.json`: layouts, `devices` such as the UGTablet pen area, overrides; `shell.json`: shell options) and `hypr/generated/` (gitignored: matugen colors, monitors).
- Code must work on x86_64 and aarch64, NVIDIA, AMD, Intel and Adreno. The NVIDIA-only parts (`hypr/core/env.lua`, `hypr/scripts/shell.sh`) switch off when NVIDIA is not the only GPU; on an ARM SoC there is no PCI vendor file, so they stay off. Check `uname -m` and the hardware before assuming a tool exists (`ddcutil`, `nvidia-smi`, a backlight, a battery, Wi-Fi).
- Write down what each machine lacks in `docs/plan.md` when a test cannot run there (e.g. Wi-Fi on the desktop).

### Setting up a machine (until the new installer, step 7)
1. Packages (on Arch Linux ARM some may have to be built from the AUR or source; Hyprland must be 0.56+ for the Lua config): `hyprland quickshell matugen hypridle hyprlock hyprsunset grim slurp wl-clipboard cliphist imagemagick jq curl playerctl wireplumber brightnessctl gnome-keyring fuzzel ydotool libnotify xdg-utils wf-recorder networkmanager bluez bluez-utils tesseract tesseract-data-eng tesseract-data-tha rust yt-dlp ffmpeg`, plus `ddcutil` for desktop monitors and `upower` on battery machines. Fonts: Material Symbols Rounded (`ttf-material-symbols-variable`), Mitr (below).
2. `git clone https://github.com/someact/SomeShell` and link: `ln -sfn <repo>/hypr ~/.config/hypr`, `ln -sfn <repo>/matugen ~/.config/matugen`, `ln -sfn <repo>/shell ~/.config/quickshell/someshell`, `ln -sfn <repo>/fontconfig/60-someshell-mitr.conf ~/.config/fontconfig/conf.d/` (move any existing config away first, never delete it).
3. Mitr: download `Mitr-{Light,Regular,Medium,SemiBold,Bold}.ttf` from `https://raw.githubusercontent.com/google/fonts/main/ofl/mitr/` into `~/.local/share/fonts/someshell/`, then `fc-cache -f`.
4. Keyboard layouts: `~/.config/someshell/hypr.json` with `{ "hyprland": { "input": { "kb_layout": "us,th" } } }` (without it only `us` loads and Super+Space has nothing to switch to).
5. Log in to Hyprland; autostart runs `hypr/scripts/shell.sh`. With no wallpaper set, the shell uses the bundled poster (`shell/assets/wallpapers/poster-moon.png`) and runs matugen. Redraw the posters at the screen's size with `scripts/poster-wallpaper.sh <w> <h>` if it is not 16:9.
6. Quick Share (machines with Bluetooth): `share/install.sh` builds the helper into `~/.local/lib/someshell/` (obexd comes with `bluez`); restart the shell.
7. Login screen (machines with SDDM): `sudo sddm/install.sh`.
8. Check: `hyprctl configerrors` (empty), `qs -c someshell ipc call island state`, `qs -c someshell ipc call control state`.

## The new shell (`shell/`)
- `shell.qml`: a wallpaper window and a `TopBar` per screen, `Shortcuts.qml` (global shortcuts `someshell:<name>`, the names `hypr/binds/keybinds.lua` uses), `Ipc.qml` (targets `island`, `wallpaper`, `theme`, `workspace`, `overview` and more; see the file).
- `core/` singletons: `Paths`, `Config` (`~/.config/someshell/shell.json`), `Theme` (palette from matugen: `Theme.ink.*` for the island, `Theme.bg/fg/paper.*` for desktop surfaces; fonts by style name), `Motion`, `Ui` (island state), `Clock`, `GameMode`, `Desktop` (the look: `desktop.json`, what edit mode changes and presets save), `Spaces` (workspace designs per number 1–10: name, what rest shows, the name flash). `core` never imports `qs.services` (no import loops).
- `services/`: one singleton per system source (`Wallpaper` runs matugen). `components/`: `Txt`, `Icon`, `Digits` (rolling digits), `Tap` (press inverts), `Chip` (a rounded choice).
- `top/`: `TopBar` (one layer window per screen, namespace `someshell:island`, input mask = badge + tray + island, keyboard only while open, `HyprlandFocusGrab` closes on an outside click), `Island` (shape, state choice, hover/click, size spring), `Badge`, `Tray`, `DockApps` (pinned + running apps), `Dock` (the separate dock bar with the Notch and Plain styles; with Dock style the TopBar itself becomes the bottom bar). `island/`: one file per island state (`Rest`, `Peek`, `Alert`, `Quiet`, `Open`, `Level`, `Flash`). Every state and page sets its own implicit size; the island never has a fixed size. Pages without a tab (`Ui.extraPages`, e.g. `clipboard` on Super+V) open only by their shortcut; read the current page as `Ui.pageId`.
- `edit/`: edit mode. `EditWindow` (Overlay per monitor while `Ui.editing`; zoom in/out is its one motion, `Ui.endEdit()` plays it before closing), `DeskCard` (the live desktop card, drawn at screen size and scaled), `EditPanel` + `tabs/` (one file per tab, loaded only while shown). `services/Editor.qml` records the look before each change (call `Editor.record()` first) for Undo.
- `widgets/`: desktop widgets, drawn inside each `WallpaperWindow` (`WidgetLayer`, `WidgetFrame`: card or bare, loads `<Kind>Widget.qml` by URL, so shared types go in `components/`, e.g. `WidgetButton`). Kinds, grid and changes in `core/Widgets.qml`; entries in `Desktop.widgets`; the Widgets tab is `edit/tabs/WidgetsTab.qml`, moving and resizing live in `edit/DeskCard.qml`. Widget colors come in as `c` (`Theme.paper` on a card, `Theme.onWall` bare). IPC `widget …`.
- `overview/`: the overview (Super+Tab), loaded only while `Ui.overview`: `Overview` (one Overlay window on the monitor it opened on; reads `hyprctl -j clients/monitors/workspaces` when it opens and again on Hyprland events; one MouseArea for hover, clicks and both drags), `OverviewPage` (one workspace), `CornerMarks`. Workspaces are shared by every monitor (1–10); `workspace_step(d)` in `hypr/lib/util.lua` gives the next/previous number.
- Drop and downloads: `services/Drop.qml` (what was dragged onto the island: `over`/`label` while dragging, `item` and `actions` after; `lib/drop.sh`), `island/Dropping.qml` (the state; not `Drop.qml`, which would clash with the service), `island/pages/DropPage.qml` (the tabless `drop` page). `services/Jobs.qml` holds running downloads and transfers (Rest and Peek show them); `services/Downloads.qml` + `lib/download.sh` (yt-dlp; `SOMESHELL_DOWNLOAD_DIR`, `SOMESHELL_DOWNLOAD_RATE` for tests). Quick Share: `share/` (Rust helper, zbus: sends through obexd and is its agent for incoming pushes; JSON lines both ways, described at the top of `share/src/main.rs`), `services/Share.qml` (starts it only with an adapter and the helper installed), `island/pages/SharePage.qml` (tabless `share`: devices, or an incoming file's Accept / Decline), the `share` control tile. IPC `drop`, `download`, `share`.
- `capture/Picker.qml` + `services/Capture.qml` + `lib/capture.sh`: the capture picker (frozen screens) with its mode bar: screenshot, text, lens, translate, color. `ipc call capture start shot|text|lens|translate|color`, `box <monitor> x y w h`, `cancel`. Alerts can be `wide` (`Ui.showAlert(..., { wide: true })`: longer text, shown longer).
- `lock/` + `services/Locker.qml`: the lock screen (style A "Headline"; B and C later as a setting). `WlSessionLock` with a `LockPage` per monitor, PAM `login`; a marker file with the Hyprland instance relocks after a crash. `ipc call lock preview` shows the page in a normal window (nothing locked, Esc closes): test there, never with a real lock (only the user's password opens it). The preview takes the keyboard; check `lock state` shows `preview: true` before sending keys with ydotool, or they land in the focused window. hyprlock (`hypr/hyprlock.conf`, lines from `hypr/scripts/lockinfo.sh`) is the backup; `hyprlock --grace 60` can be tested (a mouse move opens it). SDDM: the same page in `sddm/someshell`, installed by `sudo sddm/install.sh` (copies Mitr and the palette; rerun after a wallpaper change), tested with `sddm-greeter-qt6 --test-mode --theme <dir>`.
- `settings/`: the settings window (a `FloatingWindow` titled "SomeShell Settings", loaded while `Ui.settings`; pages in `settings/pages/` by URL, so their shared controls are in `components/`: `Select`, `IconChoice`, `Switch`, `SetRow`, `SetSection`, `SetButton`). Long lists are dropdowns, a few values are icons, on/off is a switch. `services/HyprConfig.qml` writes Hyprland options to `hypr.json` and applies them live; `services/Displays.qml` does the Displays page (IPC `displays …`; never apply a monitor change without the countdown or Keep, and always send a rule for every monitor).
- `assets/wallpapers/`: the poster wallpapers (moon is the default), drawn by `scripts/poster-wallpaper.sh`. `lib/`: `calc.js` (math), `emoji.tsv` (built by `scripts/emoji-data.sh`).
- State files: `~/.local/state/someshell/palette.json` (matugen), `wall.json`. Look: `~/.config/someshell/desktop.json`, presets in `~/.config/someshell/presets/<slug>/` (`services/Presets.qml`, `lib/preset.sh`). v1 used `colors.json`, `wallpaper.json` and `config.json`; the new names avoid clashes while both exist.
- Testing: the live shell is `qs -c someshell` (this repo). Restart it with `qs kill -c someshell`, then `hyprctl eval 'hl.exec_cmd("~/.config/hypr/scripts/shell.sh")'`; drive it with `qs -c someshell ipc call …` and real keys through ydotool. `SOMESHELL_DRY_POWER=1` makes the power page only say what it would run.
- A Hyprland release bind (the Super tap) sends a global shortcut as "released" only; `Shortcuts.qml` handles that for `island`.
- Live reload is not reliable for judging a change: after several edits it keeps running old code (seen 2026-11-02: a fixed bug stayed until a restart). Restart the shell before a screenshot that has to prove a fix.
- Keyboard in the open island (`Open.qml`): anything clickable on a page sets `kbNav` and `kbClick()` (optional `kbAlt()` for Shift+Enter, `kbHold(bool)`, `kbStep(d)` for Left/Right, `kbLeaf`, `kbField`) and holds a `KeyRing`; `Tap`, `Chip`, `ListRow`, `Tile`, `BarSlider` and `Field` already do. A bare `MouseArea` on a page is invisible to the keyboard.
- Island pages are loaded by URL, so a type in a folder under `island/pages/` (or next to a page) is "not a type" there: put a shared type in `components/` (`ControlTile`). The page's own sub-pages load by `source`.
- Qt's JavaScript has no `Array.prototype.flatMap`; build arrays with a loop. A property named `top`, `bottom`, `left`, `right` etc. on an Item clashes with its anchor lines ("Cannot override FINAL property").
- After many live reloads, `qs kill` can segfault in a Wayland destructor, and Quickshell's crash handler relaunches the shell as `quickshell` (a second copy draws over the first). `hypr/scripts/shell.sh` now stops every copy (and leftover crash reporters) before it starts, so always restart through it.

## Quickshell and Qt gotchas (learned on v1)
- Focus: a layer with `Exclusive` focus keeps it, so a `HyprlandFocusGrab` never clears on an outside click; switch to `OnDemand` once the grab is active.
- Blur: compositor blur (`BackgroundEffect`) only. An empty `blurRegion` blurs the whole surface; set it to `null` when the shape is off-surface. Wayland regions have stepped corners, so keep a region 1 px inside a rounded shape.
- Config files: ignore file changes for a moment after the shell's own write, else several writes in one handler get lost.
- Loader: never bind both `source` and `sourceComponent`; writing `sourceComponent` (even `undefined`) clears `source`, and the binding order differs between machines (the tablet showed empty pages after a switch). Set one of them imperatively.
- QML: an id named `layer` inside an Item is shadowed by `Item.layer` (delegates read the wrong object); a property named `id` is not allowed.
- QML: a property named `onX` parses as a signal handler (use `fgX`-style names). Bindings are stale inside a change handler; read the source property. `Timer.restart()`/`start()` replaces a `running:` binding for good.
- Animation: `SpringAnimation`/`Spring` only in a `Behavior` or `on <prop>`; inside `Sequential`/`ParallelAnimation` Qt segfaults (use `NumberAnimation`).
- AnimatedImage: never `cache: false` on a network URL (Qt 6.12 stack overflow); download with curl and play local files.
- Fonts: the UI font is Mitr (static files in `~/.local/share/fonts/someshell`). Qt maps every numeric weight 300–600 of it to SemiBold, so pick faces with `font.styleName` (Light, Regular, Medium, SemiBold), never `font.weight`; rebuild names with `fc-cache -f`. Mitr digits are proportional (no `tnum`). Each distinct `font.variableAxes` value opens another face: snap icon axes to a few values, never animate an axis.
- Shapes: QtQuick.Shapes, never Canvas. Images: show a screen-sized copy of a big wallpaper (Qt keeps a large decode in memory). Many `Image`s of one file at different `sourceSize`s decoding at once crashed Qt's image threads (SIGSEGV in pooled threads, libQt6Gui; the overview's 13 wallpaper pictures): give them all one `sourceSize` so they share one decode, and let the GPU scale.
- `ClippingRectangle` draws its content into a texture: never on an item whose size animates (the edit card zoomed at ~12 fps on the tablet; remade every frame). Use `clip: true` and paint the round corners over it (`edit/DeskCard.qml`).
- Names: inside a `QtObject`'s function an unqualified name that is also an id (e.g. `win`) means the id, not the object's own property; `win = null` then throws and aborts the handler. Qualify (`ptr.win`) or avoid the clash.
- IPC function names must not be `show`, `call` or `prop` (clash with `qs ipc` subcommands).
- Hot reload can silently stop applying edits after many quick changes, and new fonts need a restart: `qs kill -c someshell`, then `hyprctl eval 'hl.exec_cmd("<repo>/hypr/scripts/shell.sh")'` (`hyprctl dispatch exec` does nothing under the Lua config). After a crash the shell restarts as `quickshell`, not `qs` (`qs list --all`, `qs kill`). Never `pkill -f` a pattern that is in your own command.
- Memory: compare with a fresh start, read `Anonymous`/`Pss` in `/proc/<pid>/smaps_rollup`; an empty one-window Quickshell is already ~250 MB RSS / ~55 MB anon on the desktop.
- Hover: when a layer's shape or input region changes under a still pointer, Hyprland can send a leave and no enter until the pointer moves, so a `HoverHandler` reads "outside". Before acting on a leave, ask `hyprctl cursorpos -j` (the island does).
- Positions: never mix an anchor and an `x`/`y` binding on one item, even switched by a condition: the anchor writes `x` and the binding is gone for good (the docked island stayed stuck). A `PanelWindow`'s own `width` can read as its default (100) when it is anchored left and right; use the screen's size. A `Region { item }` does not follow an item that is animating: give the mask a still item.
- Pointer tests: move the cursor with `ydotool mousemove -x <dx> -y <dy>` (`YDOTOOL_SOCKET=$XDG_RUNTIME_DIR/.ydotool_socket`), not a Hyprland cursor warp: a warp sends no leave event. Screenshots: `grim -o <monitor>` (names from `hyprctl monitors`). `ydotool mousemove -a` has taken half the layout position on both axes (tablet at scale 2: `-a -x 360 -y 433` landed at 720,866; the desktop until 2026-11-04) but on the desktop it now lands 1:1: check with `hyprctl cursorpos` after the first jump. Relative moves are accelerated. In edit mode a press right after one absolute jump is sometimes lost (about 3 in 10; the island is not affected, real mice are not): nudge 1 px (`ydotool mousemove -x 1 -y 0`) before clicking.

## Hyprland Lua API
- Authoritative stub: `/usr/share/hypr/stubs/hl.meta.lua`; example `/usr/share/hypr/hyprland.lua`.
- Rules take flat effect fields (`hl.window_rule({ match = {...}, no_blur = true })`); unknown fields are errors.
- Springs: `hl.curve(name, { type = "spring", mass, stiffness, dampening })`, used as `spring = name`.
- `--verify-config` runs `config.reloaded` handlers; an `hl.dispatch` there segfaults it (exit 139). A reload resets Lua state without an event, so the shell rereads state on `configreloaded`.
- `hyprctl eval '<lua>'` runs code; `hyprctl repl 'return <expr>'` reads globals.

## Rules for the shell
Lazy-load every panel. Events, not polling. matugen only (no Python, no cava). Compositor blur (`BackgroundEffect`), never QML blur, and only where the design asks for it. Global shortcuts under appid `someshell`. Never hardcode this machine (monitor, GPU, tablet, layouts, absolute paths, names): detect or read from settings.
